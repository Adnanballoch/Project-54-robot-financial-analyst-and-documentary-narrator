# Project 54: Robot Financial Analyst and Documentary Narrator

**Category:** AI Robotics / FinTech
**Part of:** AutoMatrixLab

## Overview

A fully autonomous see → think → narrate pipeline where a humanoid robot analyses company financial statements from its live camera feed.

## Tech Stack

OpenAI Vision, Azure TTS, Python, Raspberry Pi
